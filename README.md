# C18

Portfolio web minimalista oscuro.  
**Diseño · Adrià Moreno** · **Desarrollo · Erik Lundgren**

## Cómo verlo

Abre `index.html` en el navegador o usa un servidor local:

```bash
npx serve .
```

## Estructura

- **Hero** — Marca C18 y presentación
- **Proyectos** — Grid de trabajos (placeholder, añadir tus proyectos)
- **Equipo** — Adrià Moreno (diseño) y Erik Lundgren (desarrollo)
- **Contacto** — Email y redes

## Capturas de proyectos

Añade en la carpeta `images/` las capturas de pantalla:
- `proyecto-cvo.png` — www.controlvo.ovh
- `proyecto-soporte.png` — www.controlvo.ovh/soporte
- `proyecto-tasaciones.png` — Portal Tasaciones

## Personalizar

1. Las capturas aparecerán automáticamente al añadir los archivos
2. Cambia `hola@c18.com` por tu email de contacto
3. Añade enlaces reales a LinkedIn, Twitter, Instagram en el footer
